# 专题内搜索

依据用户已确认的方案实施。三个专题共用搜索能力；仅匹配标题、简介、标签，不加载或检索正文。发布日期按 UTC 日历日期比较，范围包含两端；关键词忽略大小写和首尾空白。

入口位于介绍下方、文章列表上方，与已发布数量并排，仅显示 Iconify Lucide 放大镜，提供可访问名称。展开后切换关闭图标。搜索区在正常文档流中展开，250ms 弹性缓动，内容淡入上移，列表跟随；减少动态效果设置下取消动画。

条件实时生效并回到第一页。收起保留条件，清空恢复完整目录第一页。条件和结果页码写入查询参数，刷新可恢复。无结果提供清空操作；日期倒置显示明确提示。结果保留专题篇章顺序与原有分页大小选项。

边界：纯函数负责筛选和查询参数；Vue 专题浏览器负责交互状态；共享文章列表视图和分页组件负责呈现。Astro 仅传入当前专题已发布的摘要字段，保留静态页面和无 JavaScript 阅读能力。

验证：筛选规则、日期边界、空结果、数百篇分页与网址恢复的单元测试；构建及现有回归；浏览器检查展开、收起、清空、关键词、日期、分页和窄屏布局。
