# 文章专题功能设计（已确认）

## 目标与现状

为文章模块增加“文章总览 → 专题目录 → 文章正文”的阅读层级，首批专题为“365天思想实验”“《小岛经济学》解读”“《穷爸爸富爸爸》解读”，后续可以通过内容文件扩展。

现有项目是 Astro 静态站点，文章通过 `src/content/posts` 中的 Markdown / MDX 文件维护，`src/content.config.ts` 定义内容校验。当前只有一篇独立文章，没有专题数据；文章列表按发布时间倒序，正文上下篇链接也使用全站时间顺序。

## 方案比较

1. **独立专题集合（推荐）**：专题具有固定标识、标题、简介、展示顺序和独立目录页；文章可选择关联一个专题。支持空专题、连续阅读和明确的数据校验，适合长期更新。
2. 标签分组：实现较少，但标签描述的是文章主题，不适合表达期数、章节顺序或没有文章的专题。
3. 文章页内折叠分组：入口直观，但几百篇文章会让总览页面过长，专题无法拥有独立可分享的目录地址。

## 页面行为

### 文章总览 `/posts`

- 标题下方展示专题目录，采用左侧说明、右侧纵向专题条目的非对称布局；窄屏改为单列。
- 每个专题条目展示名称、简介、已发布文章数量及目录入口。
- 首批三个专题即使没有文章也显示，计数为零，目录页面显示“文章正在整理中”。
- 下方保留全部文章列表，按发布时间倒序排列；专题文章显示所属专题名称。
- 沿用现有深色背景、玻璃质感、金色与薄荷色变量，使用清晰的文字入口，不额外引入装饰图片。

### 专题目录 `/posts/series/[id]`

- 展示返回文章总览的链接、专题标题、简介、已发布篇数。
- 按文章在专题内的正整数序号升序排列，展示序号、标题、摘要和发布日期。
- 目录每页最多 30 篇；首页使用专题根地址，第 2 页起使用 `/posts/series/[id]/page/2` 等地址，并提供上一页、下一页和页码信息。
- 空专题生成正常目录页面，不显示分页。
- 未定义的专题和不存在的分页地址不生成页面。

### 文章正文

- 延续现有 `/posts/[slug]` 地址，现有独立文章地址保持有效。
- 专题文章显示“文章 → 专题名称 → 当前文章”的面包屑和专题内序号。
- 专题文章的上一篇、下一篇按照专题内序号查找，仅指向同一专题已发布的文章；跨目录分页仍连续。
- 独立文章保留现有按全站发布时间组织上下篇的行为。

## 数据与职责划分

### 内容定义

- 新增 `series` 内容集合，使用 `src/content/series/*.md`；文件名作为稳定专题标识，标题可独立修改。
- 专题字段：`title`、`description`、正整数 `order`。
- 首批标识：`365-thought-experiments`、`island-economics`、`rich-dad-poor-dad`。
- 文章增加可选的 `series` 引用和 `seriesOrder` 正整数。两者必须同时提供或同时省略。
- 普通文章继续使用原有字段，不需要迁移。

### 内容查询与校验

- 在独立的 `src/lib/posts.ts` 中集中处理专题关系、已发布文章过滤、确定性排序、文章计数、分页及相邻文章查找。
- 所有文章（包括草稿）的专题标识必须存在，同一专题内的序号不允许重复；构建失败时说明冲突文章，防止错误关系静默上线。
- 序号允许不连续，便于分批发布；草稿不进入公开列表、文章计数、分页或上下篇链接，也不生成正文页面。
- 同日期文章以文章标识作为次级排序依据；专题展示顺序相同时以专题标识作为次级排序依据。

### 展示组件与路由

- 独立的文章列表组件负责重复的文章条目展示。
- 独立的专题目录展示组件供专题首页和后续分页复用。
- 页面负责内容查询与布局组合，不在多个路由重复排序和筛选规则。
- 继续使用 Astro 静态生成，无需数据库或新的浏览器端状态库。

## 内容维护

- 更新 README，说明新增专题、归属文章、设置顺序、草稿预览限制和文件命名方式。
- 提供三个专题定义及 Markdown 写作模板说明，不将虚构的书籍解读或思想实验作为用户已发表文章。
- 文章文件保持当前平铺命名方式，专题归属由元数据表达，避免引入嵌套文件导致现有单段文章路由不兼容。

## 验收

1. 原有文章仍可从文章总览进入并正常渲染。
2. 三个专题入口及空目录均可访问，零篇文章计数准确。
3. 使用临时内容验证多篇文章的专题归属、顺序、上下篇和草稿过滤。
4. 使用超过 30 篇的临时专题验证分页边界与跨页阅读导航。
5. 错误专题引用、缺少配对字段、非正整数序号、同专题重复序号均被构建校验拒绝。
6. 检查桌面和窄屏的长中文标题、键盘焦点及目录链接。
7. 运行项目的 `npm run build`（包含 Astro 类型检查及静态构建）。

## 实施边界

本次实现专题组织和阅读路径，不扩展后台编辑器、标签页、搜索或阅读进度。工作区存在大量既有变动，实施仅修改本功能涉及的文件，不回退其他变动。
